# ETL-UNI

Projeto de ETL desenvolvido em Python para extração e armazenamento de dados de universidades em banco SQLite.

## Objetivo
Realizar o processo de ETL (Extract, Transform, Load) utilizando Python.

## Tecnologias
- Python
- SQLite3
- Black (padronização de código)

## Estrutura
- extract.py → extração de dados
- load.py → carga no banco
- main.py → execução do projeto

## Como executar

```bash
python main.py
